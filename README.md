# FARTU MASTI

Онлайн-игра «Дурак» внутри Telegram: Mini App + бот + серверная игровая логика.

## Что готово

- Авторизация через Telegram `initData` с проверкой подписи на сервере (HMAC-SHA256, срок жизни 24 ч).
- Уникальное имя 4–12 символов (английские буквы и цифры, минимум 3 буквы), проверка уникальности на сервере.
- Лобби: быстрый поиск, создание стола на 2–4 игроков, вход по коду комнаты, список открытых столов, онлайн.
- Игровой движок «Дурак» на сервере: раздача, козырь, подкидывание, отбой, добор, «бито», «взять», таймаут хода, выход игрока, переподключение.
- WebSocket-синхронизация, все действия проверяются сервером (`server/game/durak.js`).
- Чат стола (30 символов), эмодзи, фильтр порнографии и политики (мат разрешён).
- Голосовой чат через WebRTC (микрофон, отключение звука игрока, «заглушить всех»).
- Магазин: колоды, оформление стола, эмодзи у имени, эффекты появления, четыре кейса с редкостями.
- Баланс, история транзакций, история покупок, заявки на вывод, смена имени за 49 ₽.
- Статистика: партии, победы, поражения, процент, история игр и финансов.
- Админка `/admin`: пользователи, блокировки, корректировка баланса, столы, заявки на вывод, ошибки.
- Бот: `/start`, кнопка запуска Mini App, настройка Web App.

## Стек

Node.js 24 (ESM), Express 5, ws, SQLite через `sql.js`, React 19 + Vite 8.

## Структура

```
server/           Express + WebSocket, движок, магазин, кошелёк, платежи, бот
  game/durak.js   правила игры (чистые функции, тесты в tests/engine.test.js)
  game/rooms.js   комнаты, очередь, чат, голос, таймауты
client/           React Mini App (экраны, компоненты, стили)
admin/index.html  админ-панель
tests/            node:test тесты движка и фильтра
```

## Локальный запуск

```bash
npm install
npm run build      # сборка клиента в dist/
npm start          # сервер на http://0.0.0.0:3000
npm test           # тесты движка и фильтра
```

Для отладки вне Telegram включите `DEV_LOGIN=true` — на экране входа появится тестовый вход.

## Переменные окружения

См. `.env.example`. Обязательные для боевого режима:

| Переменная | Назначение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | проверка подписи initData и работа бота |
| `PUBLIC_APP_URL` | публичный https-адрес Mini App для кнопки в боте |
| `ADMIN_TOKEN` | доступ к `/admin` и `/api/admin/*` |
| `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY` | приём платежей ЮKassa |
| `PAYMENTS_RETURN_URL` | адрес возврата после оплаты |
| `YOOKASSA_PAYOUTS_ENABLED` | включает выплаты (только после согласования с провайдером) |

`PORT`, `HOST`, `DB_PATH`, `TURN_TIMEOUT_MS`, `BOT_POLLING`, `DEV_LOGIN` — необязательные.

## Telegram

1. Создайте бота у @BotFather, получите токен и положите его в `TELEGRAM_BOT_TOKEN`.
2. `/newapp` (или Bot Settings → Menu Button) → укажите URL приложения (`PUBLIC_APP_URL`).
3. При `BOT_POLLING=true` сервер сам поднимает long polling и публикует команды.

## Безопасность и деньги

- Все игровые и денежные операции выполняются на сервере; клиент не может подменить карты, результат или баланс.
- Суммы хранятся в копейках, операции идемпотентны по уникальным идентификаторам.
- Реальные пополнения и выплаты возможны только через ЮKassa после подключения ключей и подтверждения правовой допустимости модели игры. Без ключей кнопки пополнения возвращают понятную ошибку, а не имитируют успех.

## Ограничения текущего окружения

- База данных — файл SQLite. На бесплатном тарифе хостинга диск не сохраняется между пересборками, поэтому для продакшена нужен платный план с постоянным диском или внешняя БД.
- Голосовой чат использует публичный STUN; в редких мобильных сетях может потребоваться TURN-сервер.
- Платежи и выплаты требуют реальных ключей провайдера.
